Simulated delay-tolerant nodes. In a field build these are phones over Bluetooth / Wi-Fi Direct that store-and-forward when cellular is down.

How a blackout relay works

  1. You file the incident offline. It is queued in local storage.
  2. Nearby devices exchange the packet (mesh / DTN). No tower required.
  3. The first node that reaches a network uploads it to the cloud desk.
  4. Responders see type, number, and location together.
